# 리드온 / READON

강의자료의 표·수식·차트·도식 구조를 스크린리더로 읽기 좋은 문장으로 변환합니다. 자체 R 로고와 짙은 파랑(#0f0f70)을 사용합니다.

## 실행과 배포

Node.js 24 이상에서 `node scripts/prepare-vendor.mjs`로 고정 버전의 PDF·OCR 파일을 준비한 뒤 `npm run dev`를 실행합니다. 완성 ZIP에는 해당 파일이 이미 포함되어 있습니다. 로컬 주소는 http://127.0.0.1:4173 입니다.

`dist/` 전체가 정적 웹사이트입니다. 문서 변환에는 AI API나 서버 추론이 필요하지 않습니다. GitHub Pages 배포 절차는 `.github/workflows/pages.yml`에 준비되어 있으며, 저장소 Settings → Pages에서 GitHub Actions를 게시 원본으로 선택합니다. GitHub Actions 배포가 성공하면 저장소의 Settings → Pages에 공개 주소가 표시됩니다.

큰 라이브러리 파일은 저장소에 올리지 않아도 됩니다. 배포 시 npm 공식 패키지와 Tesseract 공식 저장소의 고정 버전에서 내려받고, `scripts/vendor-manifest.json`에 기록된 SHA-256을 검사합니다. 방문자의 문서는 이 다운로드 과정에 포함되지 않습니다.

## 변환 기능

- DOCX: 제목·문단·표·병합 셀, 분수·첨자·근호·행렬 등 주요 OMML 수식.
- PPTX: 제목·표, 저장된 차트 값, 명시적인 도형 연결선, SmartArt 항목과 상하 관계.
- PDF: 위치 기반 텍스트 추출, 그림·스캔 페이지를 이미지로 읽어 기기 내 OCR 실행.
- CSV/TXT/MD: 빈 셀·빈 행 보존, 표와 주요 기호를 문장으로 변환.
- 이미지: 작성자의 대체 설명을 우선 사용하고, 없으면 한글·영문 OCR 및 글자의 좌우·상하 배치를 설명.
- 읽기: 제목 이동, 문단별 듣기, 일시정지·재개·앞뒤 문단 이동, TXT 저장과 복사.

최대 20 MB, PDF 최대 60쪽입니다. 여러 단의 PDF, 작은 글자, 복잡한 수식과 도식에서는 오독할 수 있습니다. 위치만으로 인과관계나 화살표 방향을 만들어내지 않습니다. 사진의 장면이나 복잡한 그림의 의미 설명은 지원하지 않습니다. 가능하면 원본 PPTX·DOCX를 사용하세요.

## Supabase 보관함

서울 지역의 실제 Supabase 프로젝트에 연결되어 있습니다. 변환은 로그인 없이 기기 안에서 실행합니다. 사용자가 보관함 저장을 누르고 안내를 확인했을 때만 변환 텍스트와 제목을 AES-256-GCM으로 암호화해 보냅니다. 원본 파일과 그림은 보내지 않습니다.

- 암호화 키와 보관함 접근 비밀값은 각각 별도로 브라우저에서 생성합니다.
- 서버는 접근 비밀값의 SHA-256으로 RLS를 적용하고 암호문만 저장합니다.
- 웹사이트에는 공개용 publishable key만 포함합니다. 서비스 비밀키나 OpenAI 키는 사용하지 않습니다.
- 암호화에는 매번 새 12바이트 IV와 128비트 인증 태그를 사용하고 노트 ID·버전을 AAD에 포함합니다.
- 같은 브라우저에서 보관함을 다시 열 수 있습니다. 브라우저 데이터를 지우면 복구할 수 없습니다. TXT 백업을 권장합니다.
- 보관함당 최대 30개, 한 노트의 암호문 최대 600,000자, 전체 저장량 약 100 MiB, 전체 분당 60회 저장 제한을 DB에서 적용합니다.
- 직접 UPDATE는 허용하지 않습니다. 자기 보관함의 읽기·추가·삭제만 허용합니다.
- 무료 공개 서비스는 악의적 요청으로 일시적인 저장 한도에 도달할 수 있습니다. 문서 변환과 TXT 저장은 보관함 상태에 영향을 받지 않습니다.

실제 적용된 데이터베이스 구조는 `database/schema.sql`에 있습니다. 기존 프로젝트에 무작정 다시 실행하지 마세요. 새 프로젝트를 사용할 때 `dist/config.js`의 공개 URL·publishable key와 HTML의 연결 허용 주소를 함께 바꿉니다.

## 검증

표·수식·차트·연결선·문자 배치 회귀 검사, Supabase 암호화 왕복 저장, 타 보관함 접근·삭제·위조 삽입 차단, 잘못된 키의 복호화 실패를 검증했습니다. 저장 한도와 전체 저장량 제한도 실제 DB에서 검증했습니다. 자동 보안 검사에서 경고가 발견되지 않았습니다. 실제 시각장애인 사용자와 다양한 스크린리더를 사용한 평가가 추가로 필요합니다.

## 라이선스

`dist/vendor/`에 PDF.js, fflate, Tesseract.js 및 OCR 모델의 라이선스가 포함됩니다. 한국어는 tessdata_best, 영어는 tessdata_fast 모델을 사용합니다.
